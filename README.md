# EquityPulse stock screener

**Live Demo:** [realtimestockscreener.vercel.app](https://realtimestockscreener.vercel.app)

The completed application lives in [frontend](./frontend). It is a production-style Next.js 14 / React 18 real-time Indian equity screener project.

Start locally:

```text
cd frontend
npm install
npm run dev
```

See [frontend/README.md](./frontend/README.md) for features and scripts, [frontend/ARCHITECTURE.md](./frontend/ARCHITECTURE.md) for the component/state design, and [frontend/PERFORMANCE_REPORT.md](./frontend/PERFORMANCE_REPORT.md) for benchmark targets and measurement steps.
