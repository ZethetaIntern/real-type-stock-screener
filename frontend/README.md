# EquityPulse - Real-Time Indian Equity Screener

A production-style Next.js 14 / React 18 real-time Indian equity screener application.

## Features

- Real-time stock data display for Indian equities
- Advanced filtering by sector, price, volume, and market cap
- Search functionality by symbol or company name
- Live P/E ratio and market cap metrics
- Responsive dark theme design

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI**: React 18, Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
